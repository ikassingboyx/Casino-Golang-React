# Images

Hand-drawn style casino artwork. Everything except `login-bg.svg` is
generated by `frontend/scripts/casino_art.py`; edit the script and run
`python3 scripts/casino_art.py public/assets/images` from `frontend/`.

- `login-bg.svg` — login page background
- `lobby-room.svg` — lobby: the casino floor (walls, arch, chandelier, carpet)
- `lobby-<game>.svg` — lobby: one station per game (dealer, table, stools), placed by `LobbyPage`
- `bg-<game>.svg` — room behind each game's table (blackjack, baccarat, roulette, poker)

Served at `/assets/images/<file>`.
